# Baekjoon Study

Visual Studio에서 `WinterNagi.sln`을 열고 풀고 싶은 `.cpp` 탭에서 **F5** 또는 **Ctrl+F5**를 누르세요. 팀원별 외부 도구 등록, 단축키 지정, 확장 설치는 필요 없습니다. 기존 C++ 프로젝트와 같은 Visual Studio C++ 데스크톱 개발 환경(v143, Windows SDK)을 사용합니다.

| 하고 싶은 일 | 방법 |
| --- | --- |
| 입력을 넣고 결과 보기 | 풀이 탭에서 **Ctrl+F5**를 누르고 콘솔에 예제 입력을 붙여 넣습니다. |
| 중단점에서 변수 확인 | 풀이의 실행할 줄에서 **F9**로 중단점을 지정하고 **F5**를 누릅니다. |
| 다른 사람의 풀이 테스트 | 해당 `.cpp` 탭을 열고 같은 키를 누릅니다. 탭만 바꿔도 실행할 풀이가 바뀝니다. |

## 새 풀이 작성

1. 솔루션 탐색기에서 **모든 파일 표시**를 끄면 프로젝트의 필터가 보입니다. BaekJoon 아래의 문제 번호 필터를 선택하세요. 새 문제라면 BaekJoon에서 **추가 → 새 필터**로 문제 번호를 만들고, 디스크에도 WinterNagi/BaekJoon/문제번호/ 폴더를 만듭니다.
2. 문제 번호 필터를 우클릭한 뒤 **추가 → 새 항목 → C++ 파일(.cpp)**을 선택하세요. **위치**를 해당 문제 번호의 실제 폴더로 지정하고 파일명은 닉네임으로 저장합니다. 디스크에 파일이 이미 있다면 같은 메뉴의 **기존 항목**으로 등록하세요. 등록한 파일은 솔루션 탐색기에 바로 표시됩니다.
3. 평소대로 main()을 작성하고 풀이 탭에서 실행합니다. 등록된 풀이가 여러 개여도 현재 파일 하나만 빌드합니다.
4. 팀원에게 새 풀이가 프로젝트 항목으로 보이도록 .cpp 파일과 함께 Visual Studio가 갱신한 WinterNagi.vcxproj, WinterNagi.vcxproj.filters를 커밋하세요.

## 실행 예시

`WinterNagi/BaekJoon/1025/SHK.cpp`를 열고 **Ctrl+F5**를 누른 뒤 아래 두 줄을 입력하면 `9`가 출력됩니다.

```text
1 1
9
```

## 저장소의 빌드 설정

프로젝트는 빌드할 때 같은 솔루션을 연 Visual Studio에서 현재 문서의 경로를 읽습니다. 활성 문서가 문제 폴더의 `.cpp`일 때 그 파일을 포함하는 빌드용 소스를 만들고 Visual C++ 컴파일러와 링커로 실행 파일을 생성합니다. 실행 파일과 디버깅 심볼은 `build/`에 저장됩니다. 빌드 출력의 `WinterNagi:` 뒤에 선택된 파일이 표시됩니다.

기본 Visual Studio 설정에서 F5와 Ctrl+F5는 실행 전에 빌드합니다. 개인 설정으로 실행 전 빌드를 꺼 둔 경우에는 기본 빌드 동작을 복원해야 탭 변경이 반영됩니다. 컴파일 오류 창이 나오면 마지막 성공 빌드 실행을 취소하고 표시된 오류를 수정하세요.
